# 모듈 ④ 과제 — 픽앤플레이스 로봇의 자세 추정과 궤적 생성

> 범위: 25~27강 (미니 프로젝트) · 문제 6개 = 성취도 구현 항목 6개 (전 문제 루브릭 채점)

## 과제 소개

물류 창고의 픽앤플레이스 로봇은 카메라로 물체를 보고, 그 물체가 어느 방향으로 놓였는지 추정한 뒤, 현재 자세에서 집기 좋은 자세까지 부드럽게 움직입니다. 이 미니 프로젝트는 모듈 ①②③에서 만든 도구를 하나로 묶어, 점군에서 물체 자세를 추정하고 그곳까지의 궤적을 생성해 애니메이션으로 시연하는 end-to-end 파이프라인을 노트북으로 완성하는 과제입니다.

## 과제 목표 (성취도 평가 항목 포함)

- venv와 JupyterLab 환경을 구성하고 좌표계 체인을 모델링해 Matplotlib 3D로 시각화할 수 있어요.
- 회전·동차변환·쿼터니언 모듈을 통합해 camera에서 base로의 변환 파이프라인을 구현할 수 있어요.
- 쿼터니언과 회전행렬의 상호 변환과 SLERP를 구현하고 pytest로 검증할 수 있어요.
- 선형·다항식·큐빅 스플라인 보간으로 궤적을 생성하고 위치·속도·가속도 연속성을 비교할 수 있어요.
- 노이즈 낀 점군에 PCA·Kabsch·최소제곱을 적용해 자세를 추정하고 오차를 정량 평가할 수 있어요.
- 생성한 자세 궤적을 애니메이션으로 시연하고 분석 결과를 발표할 수 있어요.

## 사용 툴 또는 라이브러리 버전

- Python 3.10 이상, **venv 가상환경 + JupyterLab 4.0 이상** (Anaconda는 사용하지 않습니다)
- NumPy 1.24 이상, SciPy 1.10 이상, Matplotlib 3.7 이상, pytest 7.0 이상, ipykernel
- 애니메이션 저장에 Pillow 또는 ffmpeg가 필요합니다.
- 모듈 ③에서 만든 `rotation.py`, `transform.py`, `coordinate_chain.py` 를 그대로 가져와 사용합니다.

## 5. 물체 자세 추정 — PCA·Kabsch·최소제곱

### 구현 내용

- 아래 코드로 길쭉한 물체의 점군을 생성합니다. **시드는 42로 고정**하세요.<!-- 채점 반영 규격: 시드는 24. 아래 코드 블록의 42 는 구버전이므로 default_rng(24) 로 바꿔 사용할 것. -->
- 점군의 공분산을 고유분해해 **주축을 추출**하는 `pca_axes` 를 구현하고, 주축을 점군 위에 3D로 그리세요. 고유값 크기도 막대그래프로 함께 보이세요.
- **PCA의 한계**를 확인하세요. 길쭉한 물체 대신 구형에 가까운 점군으로 같은 계산을 돌려, 주축 방향이 불안정해지는 것을 관찰하고 그 이유를 고유값 관점에서 설명합니다.
- 기준 점군에 **알려진 회전**을 적용하고 노이즈를 더한 뒤, **Kabsch 알고리즘**으로 회전을 역추정해 참값과 비교하세요. 정합 전후의 두 점군을 나란히 그려 확인합니다.
- **오차를 정량 평가**하세요. 노이즈 크기를 0에서 0.25까지 키우며 추정 오차를 각도로 측정하고, **점 개수를 30·90·270으로** 바꿔 가며 세 계열을 한 그래프에 그리세요. 점이 많을수록 어떻게 달라지는지 해석합니다.
- 이상치를 섞은 점군에 **최소제곱으로 평면을 피팅**하고, 잔차가 큰 점을 제거한 뒤 자세 추정 오차가 개선되는지 전후를 비교하세요.

```python
import numpy as np

rng = np.random.default_rng(42)   # 시드 고정 — 바꾸지 마세요

# 길쭉한 상자 모양의 물체 점군 (x방향으로 길다)
n_points = 240
pts = np.column_stack([
    rng.normal(0.0, 0.35, n_points),   # x — 긴 축
    rng.normal(0.0, 0.10, n_points),   # y
    rng.normal(0.0, 0.05, n_points),   # z — 가장 짧은 축
])
```
